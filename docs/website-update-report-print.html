Sửa lỗi chức năng

Maps, CAPTCHA và biểu mẫu

Google Maps — đã hoàn thành

  • Sửa lỗi `Invalid 'pb' parameter`.
  • Dùng Google Maps Embed URL hợp lệ.
  • Thêm validation URL Maps trong Sanity.
  • Ngăn lưu URL tìm kiếm hoặc embed thiếu dữ liệu.
  • Thêm title cho iframe và lazy loading.

reCAPTCHA cũ — đã loại bỏ

  • Gỡ widget báo “Tên miền không hợp lệ cho khóa trang web”.
  • Gỡ dependency/script reCAPTCHA không còn sử dụng.
  • QA production kiểm tra widget cũ không xuất hiện trở lại.

Trải nghiệm & SEO

Tìm kiếm, SEO và Accessibility

Tìm kiếm sản phẩm

  • Ô tìm kiếm trong Header.
  • URL tìm kiếm dạng `/products/?search=...`.
  • Lọc sản phẩm theo từ khóa trên trang sản phẩm.
  • Giữ tương thích với static export.

SEO kỹ thuật

  • Sitemap XML
  • Robots.txt
  • URL bài viết/sản phẩm
  • Route Tuyển dụng
  • Sửa ký tự `&` trong sitemap
  • SEO title ≤ 60 ký tự
  • Mô tả ≤ 160 ký tự
  • Canonical URL
  • Open Graph image
  • No index và Alt text

Accessibility

  • Label và ID cho input.
  • Tên truy cập cho nút carousel.
  • Title cho Google Maps iframe.
  • Thẻ `main` cho Trang chủ.
  • Cải thiện tương phản màu chữ và nút.
  • Đổi phần tử click sang button phù hợp.
  • Loại bỏ Link chứa button không hợp lệ.
